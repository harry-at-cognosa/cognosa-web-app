Cognosa Deployment Topology

EC2 hosts, Docker Compose containers, and external services

Where each runtime piece of the Cognosa web app lives: the per-environment EC2 application host and its six Docker Compose containers, the GPU host for Ollama, the four cloud LLM APIs, and the AWS and external services around them. Qdrant is the vector store shown; ChromaDB and pgvector are tested drop-in alternatives behind the same group_vdbs config.
