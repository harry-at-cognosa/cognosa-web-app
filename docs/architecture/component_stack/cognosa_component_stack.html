Cognosa Component Stack

Runtime processes, the packages inside them, the libraries they are built on, and the stores they talk to

The platform is three runtime pieces plus a set of offline tools. The React single-page app runs in the browser. The app process serves it and the REST API. The rt process executes the RAG pipeline. All Python code shares the common package. LangChain lives only in rt and the ingestion tools: it is the retrieval and chat abstraction, never part of the web API.
